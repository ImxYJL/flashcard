# 로드맵 (기능 범위)

핵심 루프(**만들고 → 주기적으로 복습**)를 먼저 검증하기 위해 v1을 4개로 좁힌다. 도메인 규칙은 [DOMAIN](./DOMAIN.md) 참고.

## v1 (핵심) — ✅ 완료

> 4개 기능 모두 구현 완료. 이후 변경은 디자인 폴리시 및 v2.

### 1. 로그인
- Google OAuth 버튼 하나. 로그인 안 하면 앱 접근 불가.

### 2. 카드 생성
- 문장 붙여넣기 → textarea에서 표현 구간 드래그 → 버튼 클릭 → 선택 구간에 자동으로 `[ ]` 삽입 (`wrapSelectionAsPhrase`).
- **1문장 1표현 제약**: 카드당 `[ ]`는 정확히 하나. 이미 대괄호가 있으면 삽입은 무시되고, 다시 지정하려면 기존 것을 지워야 함.
- 선택 구간 앞뒤 공백은 보존하고 core 텍스트에만 대괄호를 씌움.
- 저장 시 `parseSentence`로 `before` / `phrase` / `after` 3컬럼으로 분리 저장.
- category(구동사/단어) **택1 선택**. (tags 입력은 v2)

### 3. 복습 큐
- `next_review <= now` 인 카드만 노출 (`isDue`).
- 클로즈 빈칸 클릭 → 정답 노출 → `'헷갈렸어요'`(`unsure`) / `'알고 있었어요'`(`know`) 채점.
- 채점 시 Leitner 박스 갱신 (`grade`): 정답이면 box +1(최대 5)·`now + 간격`, 오답이면 box=1·`now`(같은 세션 재등장).
- 자세한 규칙·간격은 [DOMAIN §복습 규칙](./DOMAIN.md#복습leitner-규칙).

### 4. 카드 리스트 (관리)
- 전체 카드 리스트, 카드 수정/삭제.
- v1은 필터 UI 없이 단순 리스트 (필터는 v2).

## v2 (후순위)

- **졸업 처리** — `grade`가 box를 5에서 캡하는 것과 별개로, box5 카드 재확정 시 모달로 `status='graduated'` 처리해 복습 큐에서 제외. (v1은 status 없이 box5 카드가 35일마다 계속 순환)
- **즐겨찾기** — `is_favorite` 토글 + 즐겨찾기만 모아보기.
- **태그 입력·표시 + 필터** — tags 칩 입력/표시, 그리고 tag·category·status·favorite 조합 필터(관리 화면, URL 쿼리 파라미터로 상태 관리).
- **잔디 (스트릭 캘린더)** — review_events 테이블 도입 후 채점마다 row 기록, 날짜별 group by count(Supabase RPC/Postgres 함수 집계), GitHub 스타일 히트맵.

## 장기 백로그 (v2보다 더 뒤, 필요성 확인 후)

- **AI 자동 구동사/단어 추출** — 필요해지면 Next.js Route Handler 1개(`/api/extract`)만 추가해 그 안에서만 Anthropic API 키 사용 (클라이언트 노출 금지).
- **리치 텍스트** (마크다운, 형광펜) — 필요성 확인되면 볼드 1개 + 형광펜 1색부터.
- **다중 사용자/일반 회원가입** — 지금은 소유자 UID 고정으로 단일 사용자 취급.
